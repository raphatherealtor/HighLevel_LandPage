## Product thesis

Traditional landing pages request contact information and promise value later. These micro-apps provide a useful preliminary result first, then offer a transparent exchange for deeper analysis or advisor help.

The near-term goal is ethical lead generation. The long-term advantage is a reusable property decision engine that compares homeowner options with explicit assumptions, evidence, and uncertainty.

## Non-negotiable principles

- Show ranges and assumptions, not invented precision.
- Keep provider credentials out of browser code.
- Collect only information needed to fulfill the stated request.
- Preserve submitted context when the visitor requests relevant follow-up.
- Never turn private HomeTwin activity into agent-readiness intelligence.
- Use one host and one backend execution pattern.
- Keep one active implementation owner per branch.
- Verify property-data rights before display, caching, or derivative calculations.
