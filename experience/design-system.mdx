## Desired impression

Calm, premium, precise, and human. The experience should feel like a trusted financial decision tool, not an aggressive funnel or generic real-estate template.

## Principles

- Hierarchy before decoration
- Warm restraint rather than sterile fintech
- Generous whitespace around important decisions
- Dense details only inside structured comparison surfaces
- Visible evidence and assumptions
- Motion that explains real state changes
- No artificial urgency

## Tokens Rapha must approve

Palette, typography and numeric style, spacing, radius, borders/shadows, button hierarchy, fields, card/table density, chart colors, icons, and motion.

## Required reference screens

Approve desktop and mobile versions of address entry, value/equity result, future spreadsheet-style Options Navigator, loading, partial-data, low-confidence, and provider-failure states.

## Accessibility baseline

WCAG AA contrast, keyboard access, visible focus, semantic labels, linked errors, reduced motion, no color-only meaning, and readable financial tables at 200% zoom.

The exact Lovable prompt is generated only after references and tokens are approved. Every micro-app must inherit the same rules.
